# 用 Codex 解放你的雙手

施倫閔老師的兩小時跨領域大學教師工作坊。網站為可直接發布的靜態 HTML、CSS、JavaScript，無需安裝套件。

- 課程：基礎與環境、Excel → Word／PowerPoint、Gmail 與 LINE、素材 → 網站、流程 → Skill、Codex／Dot 遠端交辦。
- 包含可複製操作指令、原始教材下載與最後 8 分鐘的回饋整理橋段。
- Padlet： https://padlet.com/lmshih7022/codex-s025kfjbbvfw3723kiqw
- 網站與下載檔案皆使用相對路徑，支援 GitHub Pages 專案網址。

## 教材與互動

GitHub Pages 作為課程入口與教材下載備援；Padlet 提供教材附件、成果交流、問題與建議。最後由講師以 Codex 整理當天真實回應，再核對原文。

公司資料為教學合成範例；相片為 AI 情境示意。沒有真實公司的帳務或學員個資。網站不會自動寄信、發 LINE 或產生假回饋摘要。

## 本機預覽

執行 `python3 -m http.server 8877 --bind 127.0.0.1`，再開啟 http://127.0.0.1:8877/ 。

## GitHub Pages

發布來源為 `main` 分支根目錄，保留 `.nojekyll`。檔案修改推送後，由 GitHub Pages 更新網站。
